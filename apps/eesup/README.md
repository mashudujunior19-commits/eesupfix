### RUNNING THE APP (IMPORTANT)

#### DEVELOPMENT OR TESTING MODE FOR BOTH APPS
```bash
flutter run --dart-define=env=dev --dart-define=app=all
```

#### EESUp PRODUCTION MODE
```bash
flutter run --dart-define=env=prod --dart-define=app=eesup
```

#### EESUp PRODUCTION MODE
```bash
flutter run --dart-define=env=prod --dart-define=app=my_kasi_shop
```

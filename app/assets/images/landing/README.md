# Landing scene photographs

The animated landing screen uses real photographs when these files exist
(otherwise it falls back to a vector scene). Use high-resolution files so
they stay crisp on every screen:

| File | What | Notes |
|------|------|-------|
| `street.jpg` | Street of homes, no vehicle, no people | >= 1600px on the long side |
| `truck.png` | Delivery truck loaded with groceries (crates, bags, produce) | side view, facing right, transparent background, >= 2400px wide |
| `person_1.png` .. `person_4.png` | Full-length people (natural poses, everyday clothing) | transparent background, >= 1200px tall |

Only licensed or self-shot photographs should be used.
